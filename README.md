# A Runtime for Causal Worlds: Composing Complex Systems in One Shared Loop

**English dossier v1.1 · scope note v1.1.3 · 24 November 2026**

This is the standalone English publication repository. The French edition is published separately at [Gaaboy/moteur-mondes-causaux](https://github.com/Gaaboy/moteur-mondes-causaux).

A solo project developed since August 2024, from theoretical grammar to an experimental runtime, using vibe coding on a computer with 8 GB of RAM. The engine and implementation recipes remain private. This repository contains public documentation, diagrams, high-level results, and observed limits only.
