# Causal Worlds Engine — Public Technical Dossier

**English edition · Version 1.1 · 24 November 2026**

This is the standalone English publication repository. The French edition is published separately at [Gaaboy/moteur-mondes-causaux](https://github.com/Gaaboy/moteur-mondes-causaux).

A solo project developed since August 2024, from theoretical grammar to an experimental runtime, using vibe coding on a computer with 8 GB of RAM. The engine and implementation recipes remain private. This repository contains the public dossier, presentation materials, diagrams, publication metadata, and observed limits only.
